# Das Phantom von Heilbronn – 3D-True-Crime-TikTok-Video

DNA-Spur an ~40 Tatorten (DE/AT/FR), Polizistenmord Heilbronn 25.04.2007, 300.000 € Belohnung –
2009 die Auflösung: kontaminierte Wattestäbchen. 2011 wurde der Mord dem NSU zugeordnet.
Stimme: Piper „Pavoque“ (tiefer gepitcht, leichter Hall).
